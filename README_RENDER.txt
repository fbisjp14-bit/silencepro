Silence Pro by Leinad - versão Render com vídeo

Como subir no Render:
1. Envie estes arquivos para um repositório GitHub.
2. No Render, crie um Web Service.
3. Build Command: npm install
4. Start Command: npm start
5. Se quiser, configure MAX_UPLOAD_MB=500.

O que faz:
- Áudios: remove silêncios e exporta MP3.
- Vídeos MP4/MOV/WEBM/MKV: remove as partes silenciosas do vídeo inteiro, cortando imagem e áudio juntos, e exporta MP4.
- Mantém os modos Extremo, Viral Max e Natural/Podcast.
- Mantém porcentagem de 0 a 100% dentro do círculo de carregamento.
